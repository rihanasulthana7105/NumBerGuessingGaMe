# NumBerGuessingGaMe
Key Features Implemented:
Random Number Selection:Uses python's buit-in module to pick a random target for each round.
Dynamic Feedback:Evaluates user inputs and immediately responds with "TOO high" or "TOO low"
Attempt Tracker:Maintains an attempts counter variable that increments with every valid guess and reports the final score when won.
Replay Loop:Encapsules the round logic so the user can continuously opt into new rounds until choosing to exit.
